# Island Pill

Draws one static black pill over the camera hole. Nothing else. Hyper Island keeps working as normal.

## Get the APK (no Android Studio needed)
1. Make a free GitHub account, create a new empty repository.
2. Upload ALL the files from this folder (including the hidden .github folder) to it.
3. Open the Actions tab > "Build APK" > Run workflow. After ~3 minutes download the artifact "IslandPill-apk".
4. Unzip, copy app-debug.apk to the phone and install it (allow "install unknown apps").

## Or with Android Studio
File > Open this folder > wait for sync > Build > Build APK(s).

## Set up on the phone
1. Open Island Pill > allow "Display over other apps".
2. Turn on "Show pill".
3. Move the sliders until the pill covers the camera hole.
4. HyperOS: Autostart ON, Battery > No restrictions, lock app in Recents.
